# deepseek-tui (deprecated)

This package has been renamed to **ghosty**. Install that instead:

```bash
npm uninstall -g deepseek-tui
npm install -g ghosty
```

This legacy npm package is deprecated and receives no further releases.
`ghosty` ships the canonical `ghosty` and `ghosty-tui` commands. Historical
`deepseek` / `deepseek-tui` command shims existed only in v0.8.x and were
removed in v0.9.0.

See [docs/REBRAND.md](https://github.com/blissito/ghostycode/blob/main/docs/REBRAND.md)
for the full migration story.
